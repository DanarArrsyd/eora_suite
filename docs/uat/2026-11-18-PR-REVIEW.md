## Findings corrected before publication

1. **MRP omitted components of Daily Recovery draft WOs.** Finished output from these drafts already covered MPS demand, but the draft-component query used an inner join to `mrp_orders`, excluding Daily Recovery WOs with no MRP origin. The query now accepts either an MRP-origin or a Daily Recovery-linked draft. The regression first failed because no purchase order was proposed; it now verifies that a 100-piece draft still needs 50 KG coil and 200 nuts while new FG planned quantity is zero.
2. **Material capacity reused stock already forecast for finished draft WOs.** Daily Recovery deducted released commitments but skipped linked drafts, making the same RM appear available for a second plan. Finished draft roots now consume the shared material estimate before new rows are evaluated, across target dates. Intermediate MRP drafts are not exploded again. A shortage in one component does not skip reservation of the other components. The regression first showed capacity 200 instead of 100 after a 100-piece draft; it now passes and verifies partial-component commitment too. This is a forecast calculation, not an inventory posting or physical stock reservation.
