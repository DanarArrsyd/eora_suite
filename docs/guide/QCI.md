# Quality Inspector (QCI)

Memeriksa bahan masuk dan hasil produksi.

## Menu Anda

**Materials**

- **Incoming Release** — Pelepasan bahan yang menunggu inspeksi masuk.

**Quality**

- **Pending QC Queue** — Hasil produksi yang menunggu keputusan QC.
- **Dispositions** — Keputusan QC (release, hold, rework, reject) dan release di luar kebijakan.

**Inventory**

- **Reversals** — Membatalkan dokumen yang sudah diposting, disetujui orang kedua.

## Langkah kerja

1. Materials → Incoming Release → lepas bahan yang lolos inspeksi masuk.
2. Quality → Pending QC Queue → buka lot → **Release / Hold / Rework / Reject** dengan qty.
3. Release di luar kebijakan (mis. dari Reject) → ajukan, disetujui QCS.

## Persetujuan

- Release di luar kebijakan disetujui QCS.
