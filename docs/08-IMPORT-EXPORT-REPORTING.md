# 08 — Excel, PDF, Print & Data Exchange

## Formats and architecture
XLSX export/import; PDF export; print-ready A4/A3 portrait/landscape. Central template registry with template version, document number, tenant/company logo, plant, report title, parameters, as-of timestamp, status, author (when allowed), page number, audit metadata and EORA attribution. Example: `Generated by EORA Suite | Exported on 23/12/2026 09:43:20 WIB`; use `Printed on` only when a print operation is actually known.

## Branding
Professional unobtrusive EORA footer/header, optional faint watermark for PDF (avoid obscuring content), clear Draft/Void/Confidential labels, readable grayscale. Excel uses header/footer, cover/metadata sheet as needed, typed numeric/date cells, auto-filter, freeze panes, print area and repeated headers; no giant cell watermark that breaks data use. Timezone displayed explicitly.

## Secure export
Server-side permission/tenant scope and identical filters to grid, query snapshot/as-of, queue for large jobs, progress, expiring signed download, storage cleanup, audit, notification. Escape spreadsheet formula injection and sanitize filenames. No hidden rows outside authorization scope.

## Import wizard
Versioned downloadable template → upload → file/type/size validation → staging → field mapping → row-level business validation → preview/error download → approval for sensitive actions → idempotent posting in controlled chunks → results/audit. No direct SQL writes to posted stock. Duplicate imports cannot duplicate issue/QC/FG/delivery. Row failures and partial-commit semantics must be explicit and configurable per job type.

## Libraries
Select maintained Laravel-compatible XLSX/PDF libraries via ADR after verifying licensing, compatibility, memory limits and print fidelity. Do not hard-code tool choice without repository review.
